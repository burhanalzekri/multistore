# خريطة مشروع MultiStore

## المجلدات الأساسية

| المسار | المسؤولية | ملاحظات |
|---|---|---|
| `app/` | منطق Laravel: النماذج، الخدمات، المتحكمات، Middleware، Jobs وMail | التعديلات التجارية الأساسية تكون هنا |
| `bootstrap/` | إقلاع التطبيق وملفات الكاش المؤقتة | لا تضع أسرارًا هنا |
| `config/` | إعدادات التطبيق وقاعدة البيانات والبريد والملفات والجلسات | القيم الحساسة تأتي من `.env` |
| `database/migrations/` | مخطط قاعدة البيانات وتطوراته | لا تعدّل migration مطبقًا في الإنتاج؛ أضف migration جديدًا |
| `database/seeders/` | بيانات البداية والإعدادات القياسية | استخدمها للتجهيز المحلي والاختبارات |
| `public/` | الملفات العامة التي يقدمها الخادم | لا تضع ملفات أسرار أو نسخ قاعدة البيانات هنا |
| `resources/views/` | قوالب Blade للواجهة العامة ولوحات الإدارة | واجهة المتجر داخل `storefront/` |
| `resources/css/` و`resources/js/` | أصول الواجهة التي يبنيها Vite | المصدر الرئيسي قبل إنتاج `public/build/` |
| `routes/` | تعريف مسارات الويب والـ Console | حافظ على Middleware وعزل المتجر |
| `storage/` | سجلات وكاش وملفات مرفوعة runtime | لا ترفع محتوياته الخاصة إلى GitHub |
| `tests/` | اختبارات Unit وFeature | يجب أن تبقى متتبعة في Git لأنها جزء من جودة المشروع |
| `docs/` | توثيق التحديثات والتصميم والتنظيف | لا يحتوي على نسخ أو ملفات تنفيذية |

## ملفات الجذر المهمة

- `README.md`: التثبيت والتشغيل والنشر واستكشاف الأخطاء.
- `.env.example`: قائمة إعدادات آمنة كنموذج، دون أسرار.
- `composer.json` و`composer.lock`: اعتماديات PHP وإصداراتها.
- `package.json` و`package-lock.json`: اعتماديات Vite والواجهة.
- `vite.config.js`: مدخلات بناء الواجهة.
- `Dockerfile` و`docker/`: تشغيل التطبيق بالحاوية.
- `phpunit.xml`: إعداد الاختبارات.
- `.gitignore`: حماية الأسرار والاعتماديات والكاش وملفات التطوير المحلية.

## قاعدة التنظيم

ملفات التشغيل الدائمة فقط في الجذر. أما سكربتات التجربة أو تعبئة بيانات مؤقتة أو إصلاحات لمرة واحدة فلا تُحفظ داخل نسخة GitHub؛ إذا احتاج الفريق أداة متكررة مستقبلًا فتنشأ لها Artisan Command أو توثّق كأداة مستقلة داخل `tools/` مع اختبار وتعليمات.
