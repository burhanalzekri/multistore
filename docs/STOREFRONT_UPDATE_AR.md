# تحديث صفحة المتجر

تم تطوير واجهة المتجر العامة لتكون تسويقية، واضحة، ومتفاعلة مع الحفاظ على وظائف البحث والسلة والمفضلة والتصنيفات والتتبع.

## التحديثات

- شريط عروض أحمر يعرض عرض اليوم والتوصيل السريع والدفع الآمن.
- تحديث Hero بالنص: «اكتشف منتجات تستحق التجربة» مع CTA «اشترِ الآن» باللون الأخضر.
- إضافة نصيحة اليوم أسفل Hero لتوجيه العميل إلى استخدام الفلاتر والترتيب.
- إضافة مؤشرات ثقة: 500+ متجر نشط، 94% رضا العملاء، 50K طلب مكتمل، ودعم 24/7.
- إضافة شريط تقدم بصري لتجربة التسوق.
- الحفاظ على بطاقات المنتجات مع حركة Hover، شارات الخصم والجديد والأكثر طلبًا، التقييمات، السعر، زر السلة، والمفضلة.
- إضافة فلتر مباشر حسب النوع/التصنيف إلى جانب نطاق السعر والترتيب حسب الأحدث والأكثر مبيعًا والأرخص والأعلى والاسم.
- تحسين CTA وزر إضافة المنتج إلى السلة بألوان خضراء تسويقية وتغذية بصرية أوضح.
- اعتماد Cairo للعناوين والعناصر البارزة وTajawal للنصوص.
- التصميم متجاوب للجوال والكمبيوتر، مع احترام `prefers-reduced-motion`.

## التحقق

- `php artisan view:cache`: ناجح.
- `php artisan test`: 4 اختبارات ناجحة و5 assertions.
- تمت معاينة الصفحة عبر نطاق متجر فرعي محلي مع التحقق من ظهور العرض، النصيحة، زر الشراء، فلتر التصنيف، المنتجات، والإحصاءات.

> الأرقام التسويقية الثابتة في شريط المؤشرات قابلة للاستبدال لاحقًا بإحصاءات حقيقية من قاعدة البيانات أو إعدادات المتجر.
