# دليل تنظيم الواجهة

## الهوية البصرية

- العناوين: Cairo عند توفره عبر Google Fonts.
- النصوص: Tajawal مع fallback للنظام.
- البرتقالي/الذهبي: العروض والأسعار والعناصر التسويقية.
- الأخضر: إجراءات النجاح والشراء وإشارات التوفر.
- الأحمر: التنبيهات والخصومات العاجلة فقط.
- الخلفيات: أبيض ودرجات دافئة خفيفة لتقليل التشويش.

## قواعد UX

1. زر الإجراء الرئيسي واحد وواضح في كل مساحة.
2. لا تستخدم الأحمر للزينة؛ يخصص للأخطاء أو العروض المحدودة.
3. كل عنصر تفاعلي يجب أن يملك حالة hover وfocus واضحة.
4. لا تعتمد على اللون وحده لعرض حالة المخزون أو الخطأ.
5. الواجهة تبدأ من الجوال وتستخدم شبكة مرنة للشاشات الأكبر.
6. تحترم الحركة المخفّضة عبر `prefers-reduced-motion`.

## أماكن الواجهة

- الصفحة التسويقية: `resources/views/landing/index.blade.php`.
- المتجر: `resources/views/storefront/index.blade.php`.
- تفاصيل المنتج: `resources/views/storefront/product.blade.php`.
- لوحة الإدارة المشتركة: `resources/views/layouts/app.blade.php` و`public/css/ui-polish.css`.

تُحفظ التحسينات المشتركة في طبقة CSS العامة قدر الإمكان، بينما تبقى الأنماط الخاصة بصفحة المنتج أو المتجر داخل القالب عندما تكون مرتبطة ببنيته فقط.
